# 📚 Library Management System

A real-world **Library Management System** built with Python Flask and deployed using a complete DevOps CI/CD pipeline.

## 🚀 Project Overview

This application helps manage books and students in a library.

### Features

- 📚 View available books
- ➕ Add new books
- 👨‍🎓 Add students
- 🔍 Search books
- 📖 Issue books
- 🔄 Return books
- ❤️ Application health check
- 📊 Simple library dashboard
- 📱 Responsive web interface
